# 團隊設定（team setup）規格

> 2026-09-24。公開之後，新使用者 clone 下來看到的是 Aaron 的 8 個人、連他的班表都會跑——
> 需要一個「正式開始前先組團隊」的流程。

## 決定（Aaron 拍板）

| 題目 | 決定 |
|---|---|
| 現有 8 人（小美、阿海…） | 變成「示範團隊」範本；Aaron 自己的辦公室遷到他的團隊設定，照常運作 |
| 使用者的團隊存哪 | `backend/team/`，不進 git（`git pull` 不衝突） |
| 預設範本 | 示範團隊、軟體開發團隊 |
| 沒啟用的工位 | 3D 畫面上隱藏角色（改 Unity、重建一次 WebGL） |

## 核心概念：工位（slot）是固定的，坐誰是設定的

辦公室的上限不在後端，在 Unity：場景裡預烘了 8 個角色，各有固定外觀（LimeZu 角色素材）與固定位子。
所以 setup 不是「新增幾個人」，而是「這 8 個工位啟用幾個、每個坐什麼角色」。

- **工位定義** `backend/slots.yaml`（進 git）：外觀代號（= 角色 id，例 `p17`）、座位、協作時的站位、坐姿、遞交方向、
  是不是固定崗位（櫃檯）、進不進動態指派池。以前這些寫死在 `main.py`（`WORK_DESK`、`DESK_SIDE`、`SIT_AT`、`GIFT_TOWARD`）
  與 `p10.yaml`（`post: fixed`、`pool: false`——那是**櫃檯這個位子**的性質，不是人的）。
- **角色（persona）**：名字、職務、團隊、個性、說話風格、習慣、引擎、模型、Claude Code 代號（slug）、唯讀、
  子 agent 角色對應（`sub_roles`，取代寫死的 `SUB_NPC`）、「找他問什麼」（`ask`，給看板的成員表）。
- 工位 id 永遠不變：工作紀錄、頻道資料夾（`office_<id>`）、班表都跟著工位走。換人＝換這個工位上的角色；
  以前的紀錄留著（停用再啟用會回來）。

## 檔案配置

```
backend/slots.yaml              工位定義（進 git）
backend/templates/<key>/        團隊範本（進 git）：template.yaml（標題、說明）＋ p*.yaml ＋ p*.md
backend/team/                   使用者的團隊（不進 git）：p*.yaml ＋ p*.md ＋ team.yaml ＋ schedule.json
backend/personas/               系統檔：kanban.*、office.md、codex.md（成員表改成自動產生）
```

`OFFICE_TEAM_DIR` 可以指到別的地方（測試用）。

## 流程

1. 橋啟動：`backend/team/` 沒有任何成員 ⇒ 名冊只有看板，外殼進入 **setup 精靈**。
2. 精靈：
   1. 選範本（或從空白開始）。
   2. 選工位：8 個工位卡片（外觀頭像＋位子名稱），勾選啟用；顯示「已選 N / 8」。範本預先勾好。
   3. 逐一設定每個啟用的工位：名字、職務、團隊、個性（進階：說話風格、習慣、引擎、模型、代號、唯讀）。
   4. 確認 → 儲存。
3. 儲存：驗證 → 寫 `backend/team/` → 重新載入名冊（不用重啟）→ 同步人設到各引擎 → 通知 Unity 顯示／隱藏角色。
4. 之後隨時可以從名冊的「👥 團隊設定」再開精靈調整。

## 儲存時的驗證

- 至少 1 人、最多工位數；工位不重複；名字必填且不重複（名字也是 cogito 具名 agent 的檔名）。
- 代號只准小寫英文、數字、連字號，且不重複；沒填就依工位產生。
- **有人在工作中就不准改**（改名冊會讓進行中的任務找不到人）：請收工後再調整。

## Unity（階段三）

- 新指令 `visible`：`{"agent_id": "p07", "action": "visible", "target": "0"}` 隱藏角色（關掉 renderer 與碰撞），`"1"` 顯示。
  不用 `SetActive(false)`——物件停用後就收不到下一個 `visible 1` 了。
- 橋在 Unity 握手後、以及每次團隊變更後送出：名冊裡的顯示，其他的隱藏。

## 分階段

1. **後端**：slots.yaml、team 目錄、範本、把寫死的對照表改成從工位與人設推導、API、看板成員表自動產生、
   班表搬進 team 目錄、把 Aaron 現在的設定遷到 `backend/team/`。
2. **網頁精靈**。
3. **Unity 隱藏角色**，重建 WebGL，實機驗收。

## 不做（先）

- 新增第 9 個工位（要 Unity 新角色＋房間）。
- 在網頁上換工位的外觀（外觀跟 Unity 的角色綁在一起）。
- 範本附帶班表（班表牽涉個人偏好，另外設計）。
