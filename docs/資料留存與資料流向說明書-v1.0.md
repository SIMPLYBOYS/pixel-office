## 讀法

每一類資料可能同時存在好幾個地方（橋的狀態檔、稽核帳本、引擎自己的紀錄、供應商伺服器），所以一類資料列成多列，一列是一個存放位置。每列都填 5 欄：

| 欄 | 意思 | 填法 |
|---|---|---|
| 儲存位置 | 資料實際落在哪 | 路徑，以及決定這個位置的設定鍵 |
| 保留天數 | 放多久 | 天數；沒有時間上限就寫「無上限」，並寫出實際的上限（例如張數） |
| 刪除觸發方式 | 怎麼被刪 | 自動（什麼條件）／手動（哪個介面或動作）；「封存」不算刪除，會分開寫 |
| 送至外部模型供應商 | 會不會出本機 | 是／否，送去哪家 |
| 人工可讀性 | 誰是活人、看得到 | 只能填四個值之一：**無／供應商員工或外包／我方管理員／兩者皆有** |

「我方管理員」＝老闆（Pixffice 使用者本人），以及任何能登入這台機器、打開外殼 `http://localhost:8123/shell/` 的人。這也算人工可讀，寫明，不省略。

引擎代號：**CLI**＝Claude Code、**cogito**＝cogito bot、**Codex**＝OpenAI Codex CLI。
